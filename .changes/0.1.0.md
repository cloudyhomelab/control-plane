## 0.1.0 - 2026-09-26

First release of the control plane: a REST API that lets GitHub Actions runners run terraform, packer, ansible or any other command on the host without executing anything themselves. Runners authenticate with their GitHub OIDC token and can only invoke named actions from a YAML catalog, which fixes each command's argv, its typed params, the refs it may run and the claims allowed to call it. The server fetches the code with its own access and runs the exact commit the ref resolved to, chains jobs with `input_from`, and can require a listed approver on the calling workflow's environment. The release ships `controlplane` and `cpctl` for linux amd64 and arm64, and workflows can pin the `action/` composite by tag.


### Added

- A tag-driven release process that publishes version-stamped linux amd64 and arm64 binaries of `controlplane` and `cpctl`, with `controlplane -version` and `cpctl version` to report them.
