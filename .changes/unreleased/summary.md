Releases now carry deb, rpm and Arch packages for amd64 and arm64: they install `controlplane` and `cpctl` to `/usr/bin`, the systemd unit, an example catalog at `/usr/share/doc/controlplane/examples/catalog.yml`, and create the `controlplane` system user, but neither enable nor start the service. The unit now runs `/usr/bin/controlplane` and takes its listen address from `CONTROLPLANE_LISTEN`, so a `systemctl edit` drop-in can change it and survive upgrades. A host installed by hand that moves to a package should delete `/usr/local/bin/controlplane` and its copy of the unit in `/etc/systemd/system/`, which would otherwise override the packaged one.
