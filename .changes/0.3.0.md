## 0.3.0 - 2026-11-25

Releases now carry deb, rpm and Arch packages for amd64 and arm64: they install `controlplane` and `cpctl` to `/usr/bin`, the systemd unit, an example catalog at `/usr/share/doc/controlplane/examples/catalog.yml`, and create the `controlplane` system user, but neither enable nor start the service. The unit now runs `/usr/bin/controlplane` and takes its listen address from `CONTROLPLANE_LISTEN`, so a `systemctl edit` drop-in can change it and survive upgrades. A host installed by hand that moves to a package should delete `/usr/local/bin/controlplane` and its copy of the unit in `/etc/systemd/system/`, which would otherwise override the packaged one. The project is now licensed under GPL-3.0-or-later.


### Added

- Releases carry deb, rpm and Arch packages for amd64 and arm64 that install `controlplane`, `cpctl` and the systemd unit, and create the `controlplane` user.
- Licensed under GPL-3.0-or-later.
- `examples/host-catalog.yml`, a starting catalog with `host.uptime` and `host.uname`, also shipped in the packages; the unit takes its listen address from `CONTROLPLANE_LISTEN`, so a drop-in can change it.

### Internal

- Workflows pin third-party actions to commit SHAs, and Dependabot proposes their updates weekly.
- CI builds all packages and installs, starts, reconfigures and removes the deb on every pull request.
